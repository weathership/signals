# LAN hosts + waffle menu

Advertise `tinybox.dev.vista.zndx.org`, never 127.0.0.1, on Status.surfaces
and ServerQuery PEERS. signals-ui waffle matches Gaius: 9-dot, FEDERATION
header (uppercase CSS), × close.

Waffle `/api/signals/v1/federation/surfaces` rebases **this-host** URLs
onto the browser `Host`. LAN IP open → IP links (ZT name may not resolve).
ZT hostname open → hostname links. Foreign peers are not rewritten.
