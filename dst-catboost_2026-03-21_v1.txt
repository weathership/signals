│                                                                              │
│ Context                                                                      │
│                                                                              │
│ The classification pipeline returns a flat confidence: float that conflates  │
│ "definitely Payment Card Number" with "definitely some kind of Payment       │
│ Information but unsure which sub-type." The 175-leaf annotation taxonomy has │
│  7 levels of hierarchy, and the SIGDG ontology has explicit parent_code      │
│ trees — but both are discarded at classification time (leaf-only filtering). │
│  The integrity audit found self-training target leakage and an ad-hoc        │
│ name-match boost that's really a separate evidence source disguised as an    │
│ additive constant.                                                           │
│                                                                              │
│ Goals: Replace XGBoost with CatBoost (ordered boosting eliminates leakage,   │
│ virtual ensembles provide uncertainty decomposition). Add Dempster-Shafer    │
│ belief functions so each evidence source (cosine, CatBoost, patterns,        │
│ name-match) produces an independent mass function combined via Dempster's    │
│ rule. Output belief intervals [Bel(A), Pl(A)] at each hierarchy level so     │
│ downstream UI can surface ambiguity and request targeted disambiguation.     │

│ - uncertainty(target) → Pl - Bel                                             │

│ - normalize(), is_valid property                                             │
│                                                                              │
│ dempster_combine(m1, m2) — conjunctive combination normalized by (1-K),      │
│ raises on total conflict.                                                    │
│                                                                              │
│ combine_multiple(assignments) — left-to-right Dempster combination.          │
│                                                                              │
│ FrameOfDiscernment — takes HierarchicalCategorySet + optional confusable     │
│ pairs, builds restricted focal set:                                          │
│ - Singletons: 1 per leaf category                                            │
│ - Internal nodes: descendant leaf sets for each parent                       │
│ - Confusable pairs: manually specified (ADID/GUID, BAN/PAN, etc.)            │
│ - Theta: full frame                                                          │
│                                                                              │
│ For 175 leaves + ~30 internal nodes + ~10 confusable pairs + theta ≈ ~220    │
│ focal elements (not 2^175).                                                  │

│ 3.2 src/sigint/mass_functions.py (new, ~150 lines)                           │
│                                                                              │
│ Four converter functions:                                                    │
│                                                                              │
│ cosine_to_mass(similarities, leaf_codes, frame, discount=0.3) — softmax      │
│ similarities → singleton masses, remainder → Theta                           │
│                                                                              │
│ catboost_to_mass(proba, class_codes, frame, virtual_ensembles=None) —        │

│ available, high variance → higher Theta discount                             │
│                                                                              │
│ pattern_to_mass(pattern_signals, frame, pattern_category_map=None) — maps    │

│                                                                              │
│ name_match_to_mass(column_name, frame, category_set) — replaces the additive │
│  boost hack. Exact match → 0.7 singleton + 0.3 Theta; abbrev → 0.5/0.5; word │
│  overlap → 0.3/0.7; no match → vacuous (1.0 Theta)                           │
